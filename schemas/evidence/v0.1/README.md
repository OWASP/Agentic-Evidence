# Evidence schema v0.1

Canonical JSON Schema (draft 2020-12) for `record`, `gap`, `claim`, and `bundle-manifest` (ADR-0003).
This is the published contract; the pydantic models in `src/agentic_evidence/model/` mirror it.

**Status:** No schemas until milestone M1 (see [HANDOFF.md](../../../HANDOFF.md)).
Hand-written example records for every kind in ARCHITECTURE §3.2 are in [examples/](examples/README.md); the schemas here have to validate them.
