# Code of Conduct

OWASP Agentic Evidence is an OWASP Foundation project.
Everyone participating in the project's repositories, issues, pull requests, and community channels is expected to follow the **[OWASP Code of Conduct](https://owasp.org/www-policy/operational/code-of-conduct)**.

## Reporting

If you experience or witness unacceptable behaviour, contact the project leader listed in the [README](README.md#acknowledgements), or report it directly to the OWASP Foundation as described in the OWASP Code of Conduct.
Reports are handled confidentially.
